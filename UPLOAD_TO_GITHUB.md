# Upload this repository using the GitHub website

1. Extract the ZIP on your computer.
2. Create a repository named `digital-payments-reconciliation` on GitHub.
3. Choose **uploading an existing file**, or **Add file -> Upload files**.
4. Drag the extracted CONTENTS into the upload area: README.md, source folders, SQL, Docker configuration, tests, and setup guides. Do not upload only the ZIP file or the outer extraction folder.
5. Include `.gitignore` and the safe `.env.example`. This archive does not contain an actual `.env`, credentials, generated source data, or a virtual environment.
6. Enter commit message `Add payments reconciliation platform` and click **Commit changes**.
7. The README should render on the repository home page, with `src`, `scripts`, `database`, `kafka`, `airflow`, and `tests` browsable at the root.

The project uses synthetic data generated by the included script. Screenshots can be added later after successful local runs. A successful payments Airflow DAG run is still to be confirmed; do not claim it as verified until you run it.
